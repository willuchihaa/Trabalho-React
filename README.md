## INTALAR  

1. Clonar o repositório:
```bash
git clone https://github.com/willuchihaa/Trabalho-React.git
```

2. Entre na pasta:
```bash
cd Trabalho-React
```

3. Instale as dependências:
```bash
npm install
```

4. Inicie o projeto:
```bash
npm run dev
```

5. Va na url exibido no terminal pelo navegador.

### Testes
```bash
npm test
```

### Build
```bash
npm run build
```
